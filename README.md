# Apiflux

Source code of [Apiflux](https://www.curseforge.com/projects/1793756), a small Minecraft mod that runs the Complicated
Bees machines on Create rotation through the Kinetic Dynamo. Its sister mod is
[Manacomb](https://www.curseforge.com/projects/1793766), which does the same with Botania mana.

Build with `./gradlew build`.

By Oculifelis. Downloads and the changelog are on CurseForge.
